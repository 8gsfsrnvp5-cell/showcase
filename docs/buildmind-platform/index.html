BuildMind — MVP

Кросс-проверка графика производства работ (ГПР) и ведомости объёмов работ (ВОР). Демонстрационная база знаний: дорожные работы, АСУДД, светофоры, знаки.

⚠️ Это ранний технический прототип нового этапа BuildMind. Результаты — подсказка, требуют проверки инженером ПТО. Не используйте для реальных решений без проверки.

⚠️ Разбор .pdf — экспериментальный и лучше всего работает для аккуратных табличных PDF (например, экспорт из Excel/Word). Сканы без текстового слоя (просто фотографии страниц) не читаются — для них нужен OCR, которого здесь пока нет. Если результат по .pdf выглядит странно — попробуйте .xlsx или CSV того же документа.

Поставщики материалов

Справочник поставщиков, известных именно вам — специально начинается пустым: никаких выдуманных компаний, контактов или цен здесь нет и не будет. Добавляйте сюда реальных поставщиков и материалы, которые они поставляют — тогда в оценке потребности в материалах (после кросс-проверки) BuildMind будет подсказывать, у кого из уже известных поставщиков есть похожий по названию материал.

⚠️ Совпадение — только по похожести названия материала (склонения, порядок слов), а не по характеристикам (марка, сечение, ГОСТ и т.п.). Прежде чем заказывать — обязательно проверьте, что это действительно тот материал, который нужен.
